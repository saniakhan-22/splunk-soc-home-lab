# splunk-soc-home-lab
A hands-on Security Operations Center (SOC) home lab built with Splunk, Windows, Sysmon, and the Splunk Universal Forwarder. This project demonstrates practical skills in security monitoring, log analysis, alert triage, detection engineering, incident investigation, and threat hunting.
## Objectives

- Analyze Windows security logs
- Investigate suspicious activity
- Create SPL queries
- Build security detections
- Perform incident investigations
- Map activity to MITRE ATT&CK
- Build SOC dashboards
- Document incident response procedures

## Technologies

- Splunk Enterprise
- Splunk Universal Forwarder
- Windows
- Sysmon
- SPL
- MITRE ATT&CK
